# HR Analytics Dashboard

## Project Overview
This HR Analytics Dashboard is developed using Microsoft Power BI to analyze employee data and provide actionable insights into workforce performance. The dashboard helps HR professionals monitor employee attrition, workforce demographics, job satisfaction, salary distribution, and departmental performance through interactive visualizations.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

- ## Key Performance Indicators (KPIs)
- - Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Salary
- Average Age
- Job Satisfaction Rating

- ## Dashboard Features
- - Employee demographic analysis
- Department-wise employee distribution
- Employee attrition analysis
- Gender diversity analysis
- Salary distribution analysis
- Job role analysis
- Interactive slicers for filtering data
- Dynamic KPI cards
- Charts and graphs for trend analysis
- ## Skills Demonstrated
- - Data Cleaning
- Data Transformation
- Power Query
- Data Modeling
- DAX Calculations
- Interactive Dashboard Design
- Business Intelligence Reporting
- Data Visualization
- ## Business Insights

- Identified departments with the highest employee attrition.
- Compared employee distribution across departments.
- Analyzed salary trends by job role.
- Evaluated workforce demographics by age and gender.
- Monitored key HR metrics to support data-driven decision making.
